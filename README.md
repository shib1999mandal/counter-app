# Counter App

A simple counter built with HTML and vanilla JavaScript. Use the buttons to increase, decrease, or reset the number, and the color changes to show whether it is above zero.

**Live demo:** https://shib1999mandal.github.io/counter-app/

## Features

- **Click me** adds 1 to the counter
- **Decrease** subtracts 1 and never goes below 0
- **Reset** sets the counter back to 0
- The number is **green** when it is above 0 and **black** when it is 0

## Built with

- HTML
- JavaScript (no frameworks or libraries)

## What I practiced

- Selecting elements with `getElementById`
- Handling button clicks with `addEventListener`
- Updating the page with `textContent` and `style.color`
- Controlling behavior with `if / else`

## How to run

1. Download or clone this repository
2. Open `index.html` in your browser

No installation is needed.
